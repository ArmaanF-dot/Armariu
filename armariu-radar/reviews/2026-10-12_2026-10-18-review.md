   - The recent commits ("Fix run scripts found during first real run", classifier run 20261020T172515Z) show the first real run was on about 2026-10-19/20.

   - So there are no events from 2026-10-12 to 2026-10-18 at all.
2. **The digest is labelled complete.** `2026-10-12_2026-10-18.json` has `"partial": false`, and the Markdown gives "Charges delivered: **0**" with no warning. The pipeline cannot tell "no filings" apart from "not watching". A person needs to decide this (see the maintainer note).
3. **Counts match.** Markdown, JSON and CSV all show 0. There are no internal inconsistencies, no duplicate rows and no empty borrower names, because there are no rows.
